# Changelog

## v2.0.1

**Released:** Aug 13, 2026

### Added

- Show version info on login card.
- Show update info if a new version is available.

## v2.0.0

**Released:** May 11, 2026

This version includes breaking changes in the sheet structure. Users are advised to start from a blank sheet, and transfer any existing data there.

### Added
- In the "Stock" sheet, a new "Merge into Box" column can be used to add items to an existing box, instead of creating a new box.
- Users can exit the session with the "Logout" button.

### Changed
- Login flow. If the user session has expired, require logging in again.
- Improved UI (single button for pushing to Boxtribute instead of two import buttons, column info moved into notes, summary shown before pushing).
